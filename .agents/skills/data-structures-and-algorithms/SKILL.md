# Data Structures & Algorithms Skill

## 1. Efficient In-Memory Lookups
- **Hash Tables / Dictionaries**: O(1) average lookup and insertion for session stores and fast attribute lookups.
- **Trie (Prefix Tree)**: O(k) prefix matching for autocomplete and instant search queries across thousands of scheme titles.
- **Priority Queue / Min-Heap**: O(log n) retrieval of top-K scholarship matches ordered by benefit amount or eligibility score.

## 2. Algorithmic Tradeoffs
- Always analyze Time vs. Space tradeoffs before picking an algorithm.
- Avoid O(N^2) nested loops on collections; prefer set intersections and dictionary index lookups.
