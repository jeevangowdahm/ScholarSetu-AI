# Team roles and 5-minute demo

## Suggested team split
- Member 1: frontend/UI and responsive testing.
- Member 2: Flask routes, validation and matching logic.
- Member 3: scheme data research, official-source verification and SQLite.
- Member 4: testing, report, slides, demo and viva coordination.

## Five-minute demo
1. (30 sec) State the problem and project objective.
2. (45 sec) Show the landing page and scheme catalogue.
3. (60 sec) Submit a synthetic student profile.
4. (60 sec) Explain potential match / missing data / mismatch outcomes.
5. (30 sec) Open official source and explain the verification warning.
6. (45 sec) Explain Flask + SQLite architecture and API.
7. (30 sec) Acknowledge current demo-data limitations and future scope.

## Before submission
- Run the app on the actual presentation laptop.
- Replace generic placeholders only after verifying the current official scheme notification.
- Capture genuine screenshots from your running build for the final report.
- Run all test cases and record actual pass/fail results.
- Do not claim authentication, live syncing, trained ML or official eligibility approval: these are not implemented.
